# UI review (2026-10-26, Agent C)

Method: the real windows (main, SETTINGS, CALIBRATE, MODEL SPEC, TEST MODEL, NN STATS)
were rendered with the native Qt plugin at `QT_SCALE_FACTOR` 1, 1.25 and 1.5 (before and
after), and looked at. Only `emg_app/gui/theme.py`, `tokens.py` and new assets were
changed; no logic or layout code.

## Fixed in the theme layer

| Symptom (before) | Fix |
|---|---|
| Check boxes had no tick: a checked box was a flat cyan square, an unchecked one almost invisible (border 1.6:1) | Tick glyph (`assets/icons/ui_check.png`, generated by `tools/make_icons.py`), brighter box border `#4a5263`, accent border on hover, disabled variants |
| Combo boxes had no drop-down arrow, spin boxes had no usable up/down buttons | Chevron glyphs and styled spin buttons |
| Every `QLabel` / `QCheckBox` painted the page colour as a dark stripe on panels (MODEL SPEC voting and auto-mode rows) | `QLabel, QCheckBox, QRadioButton { background: transparent }` |
| Buttons (7 px padding) and inputs (5 px) had different heights in one row | Both now `min-height: 16px` + 6 px padding, i.e. the same 30 px (`H_CONTROL`) |
| Disabled text 2.9:1 | `#6b7384`, 3.6:1; disabled check boxes, labels, spin boxes styled too |
| No keyboard focus or pressed state on buttons, no hover on inputs | `:focus`, `#primary:pressed/:focus`, input `:hover` |
| Tab bar (SETTINGS) and menus used the Fusion defaults | Styled `QTabBar`/`QTabWidget::pane`/`QMenu` in the palette |
| Header cells and tooltips cramped | Padding 6/8 px |

Dark theme only exists in this app; there is no light theme to preserve. The glyph
URLs are resolved from the package location and fall back to `none` if a file is missing,
so a missing asset costs a glyph, never a stylesheet parse error.

## Needs main (cannot be fixed from the theme)

1. **Nested borders on stat tiles** -- `emg_app/gui/widgets.py`, `_stat_tile()` (line ~434):
   `box.setStyleSheet("QFrame { ... border: 1px solid ...; border-radius: 8px }")`.
   `QLabel` is a `QFrame`, so the selector also boxes every label inside the tile (visible
   in NN STATS and MODEL STATS: each caption/value/note has its own rounded outline).
   A widget stylesheet beats the app stylesheet, so the theme cannot override it.
   Fix: `box.setObjectName("statTile")` and `QFrame#statTile { ... }`.
2. **Same pattern in the header cards** (PERSON / GESTURE / RECORDED, main window): the
   captions and values are drawn inside little outlined boxes inside the card. Same fix:
   scope the border to an object name (look for `QFrame {` in the window header code).
3. **MODEL SPEC dialog**: the HYPERPARAMETERS scroll area is cut off by the VOTING ENSEMBLE
   group at the dialog's default size (the `min_samples_leaf` row is half hidden); the
   scroll area needs a larger minimum height or a stretch factor (`dialogs/model_spec.py`).
4. **CALIBRATE dialog**: ~60 px of empty space between the GUIDED SWEEP group and the QUICK
   group, and the table at the bottom is cut by the pinned button row at 100 %; give the
   groups a tighter vertical spacing (`dialogs/calibration.py`).
5. Hint text uses `FS_XS = 9` px in many places (35 call sites pass literal 9/10 to
   `make_label`); that is small at 100 %. Raising the literals to 10/11 would help; the
   token itself was left alone because call sites mostly do not use it.

## Suggested further improvements

- A light theme: all colours are now tokens or theme constants, so a second token set would
  be a contained change; `widgets.py` still contains hard-coded colours.
- Use `COL_GOOD/WARN/BAD` for the verdict text in dialogs consistently (some use raw hex).
- Add an icon to the gear and primary buttons using the same glyph pipeline.

## Icon

`tools/make_icons.py` draws it (ring = armband, white trace = EMG envelope, on a dark
rounded tile; no third-party marks): `assets/icons/icon_{16,32,48,64,128,256}.png` and
`app.ico` (six PNG-compressed sizes, verified by loading it back). `emg_app/gui/icon.py`
loads it (never raises, empty icon if files are missing), sets the Windows
AppUserModelID, and `emg_app/app.py` calls `apply_app_icon(app)` once after the theme.

## Resolved by main (2026-10-27)

1. Nested borders on stat tiles -- fixed: `_stat_tile` frame has `objectName "card"`
   and its stylesheet is `QFrame#card { ... }`.
2. Header / button-bar cards and the MODEL STATS frames -- same fix (6 sites:
   `widgets.py`, `main_window/window.py`, `dialogs/model_stats.py`).
3. MODEL SPEC hyper-parameter scroll area -- given a 260 px floor.
4. CALIBRATE "dead space" -- intentional, not a bug: the gap is where the 22 pt
   countdown and the live-signal line appear during a capture; collapsing it would
   make the dialog jump at every capture. The table at the bottom scrolls with the
   body (the button row stays pinned).
5. Small hint text -- left as is (9 - 10 px literals at ~35 call sites); a global
   bump needs a pass over every dialog's layout and was not worth the risk of
   clipping elsewhere.
